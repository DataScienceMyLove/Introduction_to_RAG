# Introduction_to_RAG

A workshop which introduced ***retrieval augmented generation pipelines*** with an **LLM from OpenAI**

## Overview

We're going to fetch data from a .json endpoint FAQ website to create:

- firstly a **RAG** that grounds responses from the LLM
- secondly make the RAG *agentic* with function calling

The goal of this workshop is to learn the ***first principles of RAG*** with a simple *keyword search* to the beginning.

## Use case

Provide an ***assistant*** which answers automatically to the student based on the ***knowledge base*** of the **FAQ** of six DTC courses.

## Data Source

The data comes from the DataTalksCLub FAQ website https://datatalks.club/faq/ which helps learners to understand the rules & logistics to participate at their free cohorts.
